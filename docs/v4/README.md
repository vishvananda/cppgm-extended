# v4 trackers

The inventories `docs/PLAN-CPPGM-EXTENDED-V4.md` (Phase 0) consumes,
generated by `scripts/v4_inventory.sh <source-root>` from the tracked files
of this tree and of the source tree whose implementation becomes the
reference (`cppgm-run-v3codex`, pinned at `36b42987`).  Regenerate them as
phases land; each is a snapshot of the difference that remains.

- `tests-inventory.md`: per-assignment test files (identical, modified,
  only in one tree), by extension, with the modified inputs listed.
- `lanes-inventory.md`: every course and regression test unit in the
  source tree with its lane and bucket (Phase 4 moves them).
- `handouts-inventory.md`: README and Makefile differences per assignment.
- `tree-inventory.md`: dev, scripts, doc, docs, docker, shared and
  workflow files per side.

Trackers the later phases add: `ref-deltas.md` (Phase 3), `moves.md`
(Phase 4), `readme-review.md` (Phase 6).
