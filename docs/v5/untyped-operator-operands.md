# Untyped operands in operator resolution

An overloaded function name has no expression type until a candidate supplies
its function-pointer target. Operator candidate collection dereferenced that
missing type when the other operand was an enum or class. The fix skips member
and built-in candidates requiring a concrete type, while retaining non-member
candidates whose enum parameter is on either side and allowing target-directed
function selection. It adds no allocation or lookup scan.

PA7's `200-unresolved-overload-enum-*-bad.t` inputs cover all sixteen operator
probes reported by the Rust port. Each crashed the unchanged compiler and now
rejects normally. PA12's `300-overloaded-function-{enum,class}-operator-target.t`
inputs check successful calls with the overload set on both sides. GCC agrees
with all eighteen outcomes; references were generated by the ordinary runners.

## Performance evidence

Measured on wnx0008099, 2026-10-13, with identical GCC host-build flags. Baseline
source: `1074fdda`. Both binaries were frozen before measurement. PA35's unchanged
manifest-verified workload at O0 and O3 produces identical object bytes for
baseline and patched tools. `pa35/scripts/measure.pl --counter perf --no-cache`
reports patched/baseline instruction ratios of **0.999986** and **1.000000**;
ELF text size is unchanged (4,872,822 bytes).

Independent CPU-0 measurements use grouped `instructions:u,cycles:u`, all
running 100%, three A/A calibration blocks and six alternating ABBA/BAAB blocks
per level. Every observation is retained and output equality is checked on each
run. Ratios are geometric means of the within-block mean ratios; intervals use
5,000 paired-block bootstrap samples with a fixed seed.

| Level | Instructions ratio (95% interval) | Cycles ratio (95% interval) | Peak RSS ratio | Wall ratio |
| --- | --- | --- | --- | --- |
| O0 | 1.000003 (0.999986–1.000019) | 1.003851 (0.995219–1.011779) | 0.999779 | 1.003711 |
| O3 | 1.000002 (0.999994–1.000009) | 1.001873 (0.988187–1.013817) | 0.999862 | 1.001387 |

Instruction changes are below the A/A variation. Cycle and wall intervals
include parity, and the observed changes are smaller than A/A variation
(up to 1.42% cycles at O0 and 1.15% at O3). RSS is unchanged within noise.
These results show no measurable regression on this frozen workload; they do
not establish a speedup or an upper bound for every compiler input.
