1996. Reference list-initialization ignores conversion functions
Section: 9.5.5 [dcl.init.list [1]] Status: drafting Submitter: Richard Smith Date:
2014-09-04

The specification for list-initialization of a reference does not consider the existence
of conversion functions. Consequently, the following example is ill-formed:


  struct S { operator struct D &(); } s;
  D &d{s};
