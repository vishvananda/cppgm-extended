941. Explicit specialization of deleted function template
Section: 13.9.4 [temp.expl.spec [1]] Status: C++11 Submitter: Spicer Date: 14 July, 2009

[Voted into WP at August, 2010 meeting.]

According to 13.9.4 [temp.expl.spec [2]] paragraph 1, only non-deleted function
templates may be explicitly specialized. There doesn't appear to be a compelling need
for this restriction, however, and it could be useful to forbid use of
implicitly-instantiated specializations while still allowing use of
explicitly-specialized versions.

Proposed resolution (February, 2010):

Change 13.9.4 [temp.expl.spec [2]] paragraph 1 as follows:

An explicit specialization of any of the following:

-

[DELETE: non-deleted] function template

-

class template

-

[DELETE: non-deleted] member function of a class template

-

static data member of a class template

-

member class of a class template

-

member class template of a class or class template

-

[DELETE: non-deleted] member function template of a class or class template

can be declared...
