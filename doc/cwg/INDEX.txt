Offline CWG decisions and related papers
=======================================

These plain-text copies let you read the Core Working Group issues cited by
the compiler, required tests and assignment handouts without a network connection.
The catalog also includes related rules used to interpret those examples.

The issue snapshot is cplusplus/CWG gh-pages commit
38a43db15e384602a0c5debc3f7f22be32e186a1 (issue-list revision 121a, 2026-10-10).
Each file gives its original URL, status, contributor and adoption history.
manifest.json records source and text checksums.

Read the adoption note and resolution, rather than treating the original problem
statement or an earlier proposal as current wording. Earlier decisions may have
been revised again; use these texts together with ../n3485.txt and the handout.
Catalog inclusion does not assert implementation of every example or later feature.

Change markup is explicit: [DELETE: ...] is removed wording; [INSERT: ...] is
replacement wording. HTML del/ins, struck/underlined s/u, and marked blocks are
retained as annotations; the edits are not silently applied. Source code indentation
and issue/paper discussions are retained.
When an issue refers to an adopted paper instead of including its wording, read the
local paper listed below that issue. Paper contents can extend beyond C++11.

obligations and adopted corrections. Catalog inclusion does not assert
implementation of every later-language example in an issue or paper.

Adding a decision
-----------------

When a new CWG decision is cited in implementation, required tests or a handout,
add its text and provenance record, list it in this index, and add every new file
to scripts/student_export_documents.txt. Run make audit-cwg-references. The CI
source-audit job checks reference coverage, checksums and export inclusion offline.

Attribution
-----------

Issue descriptions, discussions and resolution wording remain attributed to the
WG21 contributors named in the individual source texts. Papers retain their author
and revision information. These copies are reference material, not newly authored
course wording. The canonical issue pages identify themselves as an unofficial
snapshot; their original status and source links are preserved.

CWG 2397: auto specifier for pointers and references to arrays
  File: cwg-2397.txt
  Adopted as a DR, June 2021; full issue includes complete approved wording.
  Pointer/reference array patterns may contain auto; the deduction type itself
  must not be an array. Catalog inclusion is not an exhaustive interaction claim.

  aggregate member/base initialization case.

  Historical aggregate temporary/reference member question, resolved by CWG 1696.
  Use cwg-1696.txt for the adopted wording. Inclusion does not claim exhaustive
  implementation of either issue; the compiler repair is tracked separately.

CWG 39 | CD1 | cwg-0039.txt
  Conflicting ambiguity rules; voted into the working paper, April 2005.
  Local paper: paper-n1626.txt, the complete collected final resolution.
  Lookup merges designated declarations; ambiguity of an actual object
  conversion is a separate check. Read N3485 10.2 and the final paper rather
  than the superseded proposals in the issue history.

CWG 2059 | CD5 | cwg-2059.txt
  Adopted as a defect resolution in March 2018. Removes the same-TU
  definition diagnostic obligation from linkage rules; the ODR still applies.
  Old GCC missing-definition diagnostics are not mandatory C++ correctness tests.
