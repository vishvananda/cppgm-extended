2351. void{}
Section: 7.6.1.4 [expr.type.conv [1]] Status: CD5 Submitter: Peter Dimov Date:
2017-06-26

[Accepted as a DR at the June, 2018 (Rapperswil) meeting.]

According to 7.6.1.4 [expr.type.conv [2]] paragraph 2,

If the initializer is a parenthesized single expression, the type conversion expression
is equivalent to the corresponding cast expression (7.6.3 [expr.cast [3]]). Otherwise,
if the type is cv void and the initializer is () , the expression is a prvalue of the
specified type that performs no initialization. Otherwise, the expression is a prvalue
of the specified type whose result object is direct-initialized (9.5 [dcl.init [4]])
with the initializer. For an expression of the form T(), T shall not be an array type.

It seems an oversight that void{} is not treated like void().

Proposed resolution, April, 2018:

Change 7.6.1.4 [expr.type.conv [2]] paragraph 2 as follows:

...Otherwise, if the type is cv void and the initializer is () [INSERT: or {}], the
expression is a prvalue of the specified type that performs no initialization.
Otherwise...
