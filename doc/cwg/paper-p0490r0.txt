P0490R0: Core language changes addressing National Body comments for CD C++17

This paper presents changes to the core language sections of the C++ Working Paper N4606
[1] in response to National Body comments in response to the Committee Draft for C++17,
N4604 [2].

This is a defect against C++14.

[DELETE: An object that is value-initialized is deemed to be constructed and thus
subject to provisions of this International Standard applying to "constructed" objects,
objects "for which the constructor has completed," etc., even if no constructor is

[INSERT: An object whose initialization has completed is deemed to be constructed, even

end note ] ]
Change in 12.6.2 [class.base.init] paragraph 6:

Change in 15.2 [except.ctor] paragraphs 3 and 4:

[DELETE: For an object of class type of any storage duration whose] [INSERT: If the]

US 94, GB 13, FI 21: class template deduction in explicit type conversion using a
braced-init-list
Change in 5.2.3 [expr.type.conv] paragraphs 1 and 2:

A simple-type-specifier (7.1.7.2) or typename-specifier (14.6) followed by a
parenthesized optional expression-list or by a braced-init-list (the initializer)
constructs a value of the specified type given the initializer. [INSERT: If the type is
a placeholder for a deduced class type, it is replaced by the return type of the
function selected by overload resolution for class template deduction (13.3.1.8
[over.match.class.deduct]) for the remainder of this section.]

If the initializer is a parenthesized single expression, the type conversion expression
is equivalent (in definedness, and if defined in meaning) to the corresponding cast
expression (5.4). If the type is (possibly cv-qualified) void and the initializer is (),
the expression is a prvalue of the specified type that performs no initialization.
Otherwise, the expression is a prvalue of the specified type whose result object is
direct-initialized (8.6) with the initializer. For an expression of the form T(), T
shall not be an array type.

[DELETE: A template-name corresponding to a class template followed by a parenthesized
expression-list constructs a value of a [DELETE: particular] type determined as follows.
Given such an expression T(x1, x2, ...), construct the declaration T t(x1, x2, ...); for
some invented variable t. Define U to be decltype(t), then the expression T(x1, x2, ...)
is equivalent to the expression U(x1, x2, ...).]
Drafting note: Since the braced-init-list syntax for types (as opposed to
template-names) was already valid, and there is a syntax transformation to a variable
declaration, no additional ambiguities are apparent by allowing the additional context
for class template deduction.

[ Example:

-- end example ]
