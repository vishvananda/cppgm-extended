2994. Allowing template parameters following template parameter packs that are pack
expansions
Section: 13.2 [temp.param [1]] Status: open Submitter: Jan Schultke Date: 2025-01-20

(From submission #666 [2].)

Consider:


  template <class Head, class... Tail>
  struct test {
    template <Tail..., Head>
    static void make() {}       // clang accepts, MSVC rejects
  };

  int main() {
    test<char, int, float>::make<4, 6.f, 'a'>();
  }


There is implementation divergence for the treatment of this example. It ought to be
allowed.

[INSERT: Suggested resolution:]

[INSERT: ,]

-  [INSERT: P] has a default argument (13.10.3 [temp.deduct [5]])[INSERT: , or]

-  [INSERT: that template parameter pack is also a pack expansion].
