1926. Potential results of subscript operator
Section: 6.3 [basic.def.odr [1]] Status: CD4 Submitter: Marcel Wid Date: 2014-05-13

[Moved to DR at the May, 2015 meeting.]

The definition of the potential results of an expression in 6.3 [basic.def.odr [2]]
paragraph 2 do not, but should, include the subscript operator.

Proposed resolution (November, 2014):

Change 6.3 [basic.def.odr [2]] paragraph 2 as follows:

...The set of potential results of an expression e is defined as follows:

-

If e is an id-expression (_N4567_.5.1.1 [expr.prim.general [3]]), the set contains only
e.

-

[INSERT: If e is a subscripting operation (7.6.1.2 [expr.sub [4]]) with an array
operand, the set contains that operand.]
