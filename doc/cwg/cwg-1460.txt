1460. What is an empty union?
Section: 11.5 [class.union [1]] Status: C++14 Submitter: Jason Merrill Date: 2012-02-08

[Moved to DR at the September, 2013 meeting.]

When a similar question was raised in issue 413 [2], the resolution was to remove the
use of the term. The resolution of issue 1359 [3] has now reintroduced the concept of an
“empty” union, so there is once again the need to define it.

(See also issues 1562 [4] and 1622 [5].)

Additional note (March, 2013):

The question was raised as to whether an example like


  union A {
    union {};
    union {};
    constexpr A() {}
  };
  A a = A();


is well-formed, which hinges on the question of whether A is an “empty union,” per 9.2.6
[dcl.constexpr [7]] paragraph 4 bullet 5:

-

if the class is a non-empty union, or for each non-empty anonymous union member of a
non-union class, exactly one non-static data member shall be initialized;

Must one of the empty anonymous union members be initialized for A's constructor to be
constexpr?

The issue is being returned to "review" status for discussion of this point.

See also issues 1562 [4], 1587 [8], 1621 [9], and 1623 [10].
