Integration findings, 2026-11-08:
 - PR #117 was fast-forwarded into local and remote main at 67f175d75 on
   explicit user instruction. Core tests, export, C++11, simdjson and Boost
   passed; long public/index-cpp jobs were still running at that point.
 - All nine baseline cppgm tools build with g++ 15.2.0. Immutable accepted-parent
   binaries and all tracked dev source hashes are retained in compiler-parent/.
 - Installed Ubuntu clang is 22.1.2 (1ubuntu1). Exact package source archives
   were fetched from the official Ubuntu archive, checked against the source
   descriptor's SHA256 values and unpacked with the Ubuntu patches applied.
 - Native CMake configure passes and native LLVM qualification build is running.
 - Direct cppgm link-mode configuration failed only because the course linker
   cannot resolve host -lm. The C++ atomic probe itself compiles successfully.
   CMAKE_USER_MAKE_RULES_OVERRIDE_CXX supplies explicit native link-only rules;
   all C++ compilation remains cppgm. Both atomic probes then pass, with no
   cached feature answers forced. Candidate CMake configuration now passes.
 - Clang C probes exposed a local GCC-installation-selection warning under
   -Werror (GCC 16 lacks installed C++ headers, GCC 15 has them). Final paired
   configurations must specify GCC 15 explicitly for native C as already done
   by clang++.cfg for native C++, and re-run affected probes. Initial builds
   are qualification runs, not benchmark measurements.

 - First candidate build's standard-header failures reproduced identically
   with GCC 15 and Clang 22 under -isystem /usr/include. This is CMake's
   missing default-path metadata, not a cppgm include-order language bug.
   cppgm intentionally supports direct -v queries, while CMake's ABI probe
   adds -v to compilation. The rules file disables that verbose probe flag
   and initializes the exact default include paths read from the built-in
   generated configuration. CMake then compiles/links its actual ABI probe:
   ELF, 8-byte pointers, little endian. Fresh candidate configuration passes
   with explicit native C GCC-15 selection and successful PIC/atomic probes.
