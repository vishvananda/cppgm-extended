Compiler memory measurement correction (2026-11-06)

The prior Linux perf wrappers put GNU time around perf. That measures the
maximum RSS of the command subtree, including the resident profiler. A child
using less memory than perf can therefore change without changing reported
RSS. A touched-allocation control confirms the effect: 4 MiB and 8 MiB children
report 4980 and 9204 KiB in getrusage, while both outer time observations report
17384 KiB. An inner time and a direct time match each child's own getrusage.
