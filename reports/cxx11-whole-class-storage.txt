Behavior and implementation

CXX11-027 previously exhausted a 48 MiB address-space limit for a one-MiB
constexpr class aggregate or by-value constexpr parameter. Ordinary initialize
and new_object paths counted and allocated every logical subobject, even when
a small shared type graph described the object. The repair uses the existing
immutable shared class payloads and lifetime-owned copy-on-write paths for
compound classes. A translation-unit-local shape check preserves the cheap
flat-class path. Dense array expansion/storage limits remain in force.

PA16:300 owns object-valued constant evaluation and constexpr parameters.
The two bounded controls check both extreme leaves, distinct subobject places
and native loads. Neighbor controls cover value independence, constructors,
dangling parameters, inactive unions and runtime-only member reads. Original
C++11 aggregate/constexpr rules permit these inputs; no later CWG rule is needed.

CXX11-028 was exposed while checking omitted nonzero/default-argument class
constructors. An omitted array of aggregate members unconditionally zeroed its
storage, losing nested constructors and runtime side effects. The repair takes
the zero shortcut only after the existing typed zero-default proof succeeds;
otherwise it uses the bounded aggregate-array initialization path. PA16:300
controls cover single and multidimensional omissions and deleted constructors;
PA11:200 covers the earlier ordinary-runtime constructor effects. N3485 8.5.1p7
requires empty-list initialization of omitted members, including those effects.
