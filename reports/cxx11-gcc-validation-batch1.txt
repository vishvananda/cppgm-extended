The grouped repair passes full validation and the normal performance gate.
GCC improves from 3774/4092 to 3800/4092 (92.86%), clearing 26 configurations

There remain 292 failing GCC configurations from 146 distinct sources.

Changes grouped for validation

- A union's non-static data member cannot have reference type. Preserve
  ordinary class references, static references, pointers and substituted types.
- Constructor using-declarations must name a direct base. Dependent base lists
  defer validation until substitution; instantiated unrelated bases still fail.
- Reuse the existing typed pack walker for ordinary typedefs and data members,
  and inspect outer class packs in ordinary member-function declarations.
  Nested expansions retain their existing meaning; do not instantiate bodies
  just to search for errors.
- Include the previously prepared implicit-object cv correction in noexcept.

Regressions and validation

18 new required controls are in PA11:500, PA12:300, PA14:100 and PA15:200,
after reading the owning handouts. Eight prepared PA6:300 noexcept fixtures
are included. All 26 cases pass both dialects at O0/O2: 104 configurations each
with cppgm, GCC 15.2 and Clang 21.1.8. Positive controls cover valid static
union references, class references, pointers, direct aliases, dependent base
packs, expanded parameter/typedef packs and object-cv neighbors.

The parent compiler exposes the intended defects. A first candidate exposed
premature checking of a dependent base list; positive/negative substitution
guards were added before the final candidate. The superseded results remain
in the evidence directory and are not acceptance evidence.

The integrated candidate passes 9541/9541 strict tests, affected PA6/11/12/14/15
suites, modern C++ checks, debug info, self-host through PA5, inception, all
architecture/format/file/placement audits, CWG/student document checks, harness
checks, PA35 quick and smoke. The student export preserves all 105 offline CWG
catalog files, validates 42 reference wrappers and runs 96 accumulated required
regression controls, including every fixture in this batch.
