Typed constexpr-reference checkpoint (2026-11-06)

Compiler commit 212b6c031 preserves typed reference initializer lists and
compact array values. This checkpoint is measured and verified, but the
reference family remains open: the final neighbor sweep found CXX11-023 and
CXX11-024. The goal is still the full cxx11-gap-plan.txt, not this checkpoint.

Implementation at the checkpoint

Global direct braces, local reference initialization and aggregate reference
members use the typed temporary/direct-binding facts. A directly bound element
keeps its identity; an array or class temporary retains its initializer list
and constructor facts. Array prvalues materialize directly in their storage.

An array ConstValue stores its explicit prefix and full logical type bound.
Its omitted tail is indeterminate until initialization proves zero values.
Reads retain the original object/offset identity; writes expand through the
storage budget. Nonliteral or runtime prefixes fail optional probes early.
Nonzero constexpr defaults are sampled before dense expansion; that expansion
uses a 16 MiB-equivalent value budget. Required constant expressions outside
the evaluator's limits reject; ordinary runtime initialization remains usable.

Constant lowering consumes these values and typed layouts. Sparse bit-field
byte contributions replace a whole-object scratch image. The existing Itanium
null-member-pointer patcher retains -1 tails and nonnull zero-offset members.
Reference-array lowering reuses the semantic initialization value.

CXX11-022's independent functional-cast reducer exposes an array cv guard:
array qualification is carried by the leaf element. Bit-cast encoding reads
zero tails without mutating published nested values. A repeated-cast regression
with an intervening evaluation caught scratch pointers in an intermediate
implementation; the failed observation is retained.
