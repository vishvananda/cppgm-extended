Runtime-valued prefixes prevented static data emission, and lowering then
expanded every omitted element of the array. The parent exhausted 512 MiB
while lowering a giant lifetime-extended reference array. This is an original
N3485 8.5.4p3 / 8.5.1p7 implementation-scaling issue, independent of later CWG
decisions. Its runtime semantics include construction, volatile accesses,
member-pointer null representations, temporary lifetime and exception cleanup.

The fix consumes the existing typed initializer facts. After explicit clauses
finish, an omitted suffix longer than eight elements uses bulk zeroing when
the type permits it, or one typed initialization loop otherwise. The existing
member-pointer ABI walker patches null data-member pointers. Type inspection
visits element types and members rather than the implicit extent. Existing
counted cleanups track completed scalar elements and rows at runtime, retaining
constructor/default-argument temporary order and once-only reverse destruction.
A completed nonthrowing member-array tail also survives until a later member
constructor can throw. Automatic scalar arrays and padded string arrays use
the same machinery. Small and fully explicit arrays keep their existing paths.

A cursor-only helper had a second linear walk through omitted nested array
elements even after emitted IR became compact. The final candidate stops that
walk once no explicit clauses remain, or an element consumes none. Retained
v2/v3 diagnostic counters show about 4.50M/23.36M/306.47M versus
4.481M/4.483M/4.485M instructions for nested bounds 1024/1048576/16777216.
These single diagnostic samples motivated the revision; the final scaling
experiment supplies the separately declared acceptance measurements.

The v3 absolute measurements then exposed a further native emitter estimate:
zero_bytes computed the encoded size of every hypothetical scalar store before
choosing rep stosb. Scalar native emission reached 3.226 billion instructions
for a four-gigabyte tail, with constant-size output. Helper native emission
also failed its scaling gate. Both failures and all 376 observations remain
retained. The revised estimate stops as soon as stores already exceed the
string-operation setup; later stores cannot change the choice. This bounds
compiler work and avoids unsigned accumulation overflow without changing the
selected encoding on ordinary inputs.
