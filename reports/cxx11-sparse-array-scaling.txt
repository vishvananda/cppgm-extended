Compilation must read distinct source input, so distinct class definitions have
a linear lower bound. An implicit array extent is different: retain a zero
range and check its element type once. Compiler work can then be independent
of the number of omitted elements. Native nonzero data still has to emit its
bytes; zero-initialized writable storage can use BSS.

The immutable candidate was measured on CPU 84 with ASLR disabled, perf user
instructions/cycles, scheduling checks, GNU time/RSS and output hashes. There
are three warmups and five measured repetitions for each extent and phase.
The CPU/address-space/file caps are 5 seconds, 512 MiB and 16 MiB. All raw
observations are retained. Wall time is descriptive under load; the counter
and memory gates are authoritative. No macOS hardware-counter pass is claimed.

CXX11-010 is closed: an empty subaggregate cannot silently consume no clause
during brace elision. The fix preserves substitution failure in immediate
context, explicit empty braces, omitted trailing members, required constructor
calls and member-pointer ABI null values.

CXX11-007 remains partially resolved. The original full source now rejects
promptly at the GNU imaginary literal 0i; it is not an upstream test pass.
After removing GNU-only blocks, its C++11 core passes all six syntax cells and
four host assembly cells, but still exhausts memory in LowIR emission. Two
independent original C++11 emission gaps are reduced and left open:
  CXX11-011: const/rvalue array-reference temporaries (PA10/12 provisionally).
  CXX11-012: constexpr pointer-returning prefixes (PA16 provisionally).

LowIR program and passes eight prefix/zero-range layout predicates, including
