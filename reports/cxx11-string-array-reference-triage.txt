CWG1232 was adopted in March2011 and establishes array temporary creation.
It does not date every later list-conversion rule. CWG1467's June2014 proposal,
moved to DR in November2014, explicitly adds identity list conversion from a
suitably typed single string literal to a character-array reference target.
The original13.3.3.1.5p2 array-element-conversion rule lacks that provision.
Those ranking neighbors are later-DR compatibility requirements; both kinds
remain in this campaign's repair scope.
